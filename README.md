# Thermal Bill Generator

A single-page website for making thermal-printer style bills (receipts) for a shop or restaurant.

## Features
- Shop name, address, GSTIN, tagline and footer (saved in the browser)
- Quick menu: save items with rates, tap to add to the bill
- Qty × rate = amount, subtotal and big payment total (Cash / UPI / Card / Credit)
- Optional GST lines (included in price, or added on top), split into CGST / SGST
- Packing-counter slip on top of the bill
- Auto bill number and date/time, COPY / ORIGINAL label
- 80 mm and 58 mm roll sizes
- **Print**: a roll-sized PDF that is exactly as long as the bill (one strip, or slip and bill cut separately)
- Save as image, or copy as text for WhatsApp

## Use
Open `index.html` in a browser, or turn on GitHub Pages (Settings → Pages → Deploy from branch → `main` / root).
